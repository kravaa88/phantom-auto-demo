# BMW M4 Competition M Package

Model by [𝙎𝙍𝙏 𝙋𝙚𝙧𝙛𝙤𝙢𝙖𝙣𝙘𝙚™](https://sketchfab.com/TheRealSRT).

[Original model](https://sketchfab.com/3d-models/bmw-m4-competition-m-package-5c0a2dafb1ad408d9fc9eeef9aee531b) · [Creative Commons Attribution 4.0 International](https://creativecommons.org/licenses/by/4.0/)

The GLB is the [optimized derivative distributed by lukaizj](https://github.com/lukaizj/car-mod-saas/blob/main/public/models/ATTRIBUTION.md). It uses Meshopt geometry compression and WebP textures up to 1024 px and retains the engine bay. Its embedded attribution is intact. This demo changes the body paint and lighting and separates the original hood geometry at runtime. The accompanying triangle mask is derived from the same licensed model. The fallback still is rendered from the modified scene.

SHA-256 of `assets/bmw-m4.glb` is `9379539798ba1a3d79ebe52d52469778af6334e8261e834536d5cd4726c720a5`.

BMW model names and marks identify the depicted vehicle. PHANTOM AUTO is a PHNX Web Studio concept.

Three.js 0.170.0 and its bundled loader, environment and decoder are distributed under the accompanying notices in `assets`. The GLTFLoader utility import path was adjusted for this site's static layout.
