# BMW M4 Competition M Package

Model by [𝙎𝙍𝙏 𝙋𝙚𝙧𝙛𝙤𝙢𝙖𝙣𝙘𝙚™](https://sketchfab.com/TheRealSRT).

The GLB is the [web derivative distributed by lukaizj](https://github.com/lukaizj/car-mod-saas/blob/main/public/models/ATTRIBUTION.md). The derivative uses Meshopt geometry compression, WebP textures up to 512 px, and omits hidden meshes and unused textures. Its embedded attribution is intact. This demo changes the body paint and lighting at render time. The fallback still is rendered from the same modified scene.

SHA-256 of `assets/bmw-m4.glb` is `1a072ff0aee180b1c13d60c0ae47c93e7c151240c532b60101449a651531b3e1`.

BMW model names and marks identify the depicted vehicle. PHANTOM AUTO is a PHNX Web Studio concept.

Three.js 0.170.0 and its bundled loader, environment and decoder are distributed under the accompanying notices in `assets`. The GLTFLoader utility import path was adjusted for this site's static layout.
